# Keep it small

This is a family tutor, not a platform. Prefer a small change with a behavioral test to new services or abstractions.

- Run `npm test` and `npm run build` before a pull request.
- Preserve learning rules unless a change explicitly revises them.
- Never silently discard a local save, pending answer, or newer server revision.
- Keep persistence separate from the learning engine.
- Use synthetic records in tests. Never commit student data, cookies, passwords, actual deployment details, or private environment files.
- Check rendered flows after UI changes, including the large car layout.
- Include the reason, evidence, and limitations in a pull request.

Public visibility does not itself grant an open-source license.
