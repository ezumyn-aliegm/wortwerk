# Security

Use on a trusted home network behind HTTPS and a private-network access restriction. The shared password is for one family; this is not a multi-tenant service.

Never attach real progress, passwords, cookies, or private infrastructure details to a public issue. Report vulnerabilities privately to the repository owner, using GitHub private vulnerability reporting when enabled.

The public app shell contains lesson content only. Progress requires a session cookie. Offline copies remain accessible to people using that browser profile. Changing the password invalidates cookies but cannot erase offline copies remotely.

Keep Node and dependencies updated. Retain the data volume when replacing a container, and maintain private backups. Do not expose the backend directly to the internet.
